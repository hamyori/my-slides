01/Herencia · Concepto

Una subclase es una versión especializada

Adquiere

Lo común, una sola vez

La clase derivada hereda atributos y métodos de la superclase, sin volver a escribirlos.

Relación «es-un»

Un perro es un animal

Toda la interfaz de la base está disponible en la derivada: nombre, edad y comportamiento común.

Especializa

Lo propio, en la derivada

Lo común sube a la base; lo específico de cada especie vive en su propia clase y no toca a las demás.

COMÚN → clase base ESPECÍFICO → clases derivadas SIN DUPLICAR CÓDIGO → una jerarquía, no copias

01/Herencia · El caso Animal

Base Animal; derivadas Perro, Gato y Vaca

Animal // estado común ├── nombre // protected ├── edad // protected └── hacerSonido() // virtual ├── Perro : public Animal ├── Gato : public Animal └── Vaca : public Animal // cada derivada llama al constructor base // y añade sus propios rasgos
Clase base

Animal

Centraliza el estado común —nombre y edad— con acceso protected: visible para las derivadas, oculto hacia afuera.

Clase derivada

Perro, Gato, Vaca

Usan : public Animal, llaman al constructor base y añaden rasgos propios de cada especie.

Ventaja

Escala sin duplicar

Una nueva especie es una clase nueva sobre la misma base: nada común se vuelve a escribir.

LLAMADA AL CONSTRUCTOR BASE Perro(string n, int e) : Animal(n, e) { /* rasgos propios */ }

03/Comparativa técnica

Sobrescritura vs. sobrecarga

ASPECTO
Sobrescritura (override)
Sobrecarga (overload)
Ámbito de clases
Entre la clase base y la derivada.
Dentro de la misma clase, sin requerir herencia.
Firma del método
Mismo nombre, mismos parámetros y mismo const.
Mismo nombre con distintos parámetros.
Palabras clave
virtual en la base y override en la derivada.
No usa virtual ni override.
Momento de enlace
En ejecución: enlace dinámico (vtable).
En compilación: enlace estático.
Ejemplo práctico
hacerSonido() en Animal, Perro, Gato y Vaca.
alimentar(comida) vs. alimentar(comida, gramos).
08
03/Comparativa · Regla rápida

Cómo distinguirlas en segundos

Misma firma · otra clase

Sobrescritura

  • Entre la clase base y una derivada.
  • Firma idéntica: parámetros y const incluidos.
  • La base usa virtual; la derivada, override.
  • Se decide en ejecución, según el tipo real.
⇒ ENLACE DINÁMICO
void hacerSonido() const override;
Varias firmas · misma clase

Sobrecarga

  • Dentro de la misma clase, sin herencia.
  • Mismo nombre, distintos parámetros.
  • Sin virtual ni override.
  • Se decide al compilar, en el punto de llamada.
⇒ ENLACE ESTÁTICO
void alimentar(string comida); void alimentar(string comida, int gramos);

04/Estructura de clases

La jerarquía, en C++

class Animal {protected: string nombre; int edad;public: virtual ~Animal() {} virtual void hacerSonido() const;}; class Perro : public Animal {public: void hacerSonido() const override { cout << "¡Guau, guau!\n"; }};
Protected

Estado compartido

Perro, Gato y Vaca usan nombre sin exponerlo al exterior.

Virtual

La puerta dinámica

Declarar virtual en la base habilita la resolución en ejecución.

Override

Firma verificada

El compilador comprueba que la firma de la derivada sea exacta.

Herramientas del deck

Presentación

    Tarjetas de repaso

    ¿Qué relación modela la herencia?

    Una relación «es-un»: la clase derivada es una especialización de la base y hereda sus atributos y métodos.

    ¿Para qué sirve protected en la clase base?

    Para que las clases derivadas accedan al estado común (nombre, edad) sin exponerlo públicamente.

    ¿Qué habilita declarar un método virtual?

    El enlace dinámico: la llamada se resuelve en ejecución según el tipo real del objeto, consultando su vtable.

    ¿Por qué el destructor de una base polimórfica debe ser virtual?

    Para que borrar un puntero base invoque el destructor derivado: se libera todo y se evitan fugas en colecciones.

    Diferencia entre sobrescritura y sobrecarga

    Sobrescritura: misma firma, entre base y derivada, con virtual/override y enlace dinámico. Sobrecarga: mismo nombre con distintos parámetros en la misma clase, con enlace estático.

    ¿Qué demuestra la ejecución en vivo?

    Un vector<Animal*> recorre Perro, Gato y Vaca; cada uno responde con su propio sonido: un bucle, múltiples comportamientos.
